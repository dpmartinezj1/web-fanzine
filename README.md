# web-fanzine

La primera idea que tengo para el web fanzine es adivinar diferentes canciones de artistas. Va a haber un menú donde se pueden seleccionar los artistas. Luego de presionar sobre el nombre del artista se abre otra página donde se juega. En esa página habrá un bestiario con álbumes de este artista: si sale 3 veces la misma foto del álbum, suena una canción. En la siguiente página van a haber 5 opciones del nombre de la canción, y si se presiona la canción correcta salen serpentinas. Esto será con 3 artistas diferentes.
