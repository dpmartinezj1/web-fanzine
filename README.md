# web-fanzine
La primera idea que tengo para el web fanzine es adivinar diferentes canciones de artistas, va a haber un menu donde se pueden seleccionar los artistas. Luego de precionar sobre el nombre del artista se abre otra pagina donde se juega, en esa pagina habra un bestiario, con albumes de este artista, si sale 3 veces la misma foto del album suena una canción. la siguiente pagina van a haber 5 opciones del nombre de la canción, si se presiona la canción correcta salen serpentinas. Esto será con 3 artistas diferentes.
